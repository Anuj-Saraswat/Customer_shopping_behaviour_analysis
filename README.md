# Customer Shopping Behavior Analysis

## Overview

An end-to-end data analytics project focused on understanding customer purchasing patterns, spending behavior, product preferences, customer segments, and subscription behavior using **3,900 transactions**.

## Dataset

* **Records:** 3,900
* **Columns:** 18
* Contains customer demographics, purchase details, product information, discounts, ratings, shipping, previous purchases, and subscription status.
* **Missing values:** 37 in the Review Rating column.

## Tools & Technologies

* Python
* Pandas & NumPy
* MySQL & SQL
* Power BI
* Jupyter Notebook

## Project Workflow

1. **Data Preparation & EDA** — Loaded and explored the dataset using Python, handled missing values, standardized columns, and performed consistency checks.
2. **Feature Engineering** — Created `age_group` and `purchase_frequency_days` features.
3. **SQL Analysis** — Used MySQL to analyze revenue, customer segments, product performance, discounts, repeat purchases, subscriptions, and age groups.
4. **Power BI Dashboard** — Created an interactive dashboard to visualize the key findings.
5. **Business Insights** — Derived recommendations related to customer retention, subscriptions, discounts, product positioning, and targeted marketing.

## Key Analysis

The project answers business questions related to:

* Revenue by gender and age group
* Customer loyalty and segmentation
* Subscriber vs. non-subscriber behavior
* Repeat purchases and subscriptions
* Product ratings and popularity
* Discount usage
* Shipping preferences

## Project Files

## Conclusion

This project demonstrates an end-to-end analytics workflow, from **raw data preparation and exploration to SQL analysis, visualization, and business insights**.
